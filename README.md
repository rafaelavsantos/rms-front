# Sistema de Gerenciamento de Leituras

Aplicação desenvolvida para auxiliar no gerenciamento e acompanhamento de leituras, permitindo organizar livros, controlar o progresso de leitura e acompanhar o status de cada leitura de forma simples e intuitiva.

## Funcionalidades

- Cadastro de leituras
- Edição e remoção de leituras
- Controle de status da leitura
- Acompanhamento de progresso
- Organização das leituras em andamento e concluídas
- Interface prática e responsiva

## Objetivo do Projeto

O projeto foi desenvolvido com o objetivo de praticar conceitos de desenvolvimento web, organização de aplicações e gerenciamento de estado, além de oferecer uma solução simples para controle pessoal de leituras.

## Tecnologias Utilizadas

- Vue.js
- JavaScript
- HTML5
- CSS3
- LocalStorage / JSON Server *(caso esteja utilizando)*
